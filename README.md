# Pizza-Sales-Analysis
## Project Overview
SQL analysis of pizza sales data to identify sales trends and business insights.

## Dataset
The dataset contians pizza order details including:
-ORDER ID
-PIZZA Name
-Pizza Size
-Quantity Sold
-Order Date
-Order Time
-Order Price
-Unit Price
-Total Price

##Total Used
-Sql(MySQL)
-GitHub
-Excel

## Business Questions Answered
-What is the total revenue generated?
-How many orders were placed?
-How many pizzas were sold?
-What is the average order value?
-Which pizzas are the top sellers?
-Which pizza categories generate the most  revenue?
-Which pizza sizes are most popular?

Aggregate functions(SUM, COUNT, AVG)
